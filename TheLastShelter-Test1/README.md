# The Last Shelter — Mobile Game QA Testing

## Project Overview

This project documents a hands-on QA testing exercise conducted on *The Last Shelter*, a mobile game.

The objective was to evaluate key gameplay features, user interactions, application behavior, and potential defects through functional and exploratory testing.

## Testing Environment

- **Platform:** Android
- **Device:** Samsung Galaxy A06
- **OS:** Android 16
- **Testing approach:** Functional testing and exploratory testing
